# Resistor Combination Calculator

## About the Project
The Resistor Combination Calculator is a Python programme developed to calculate the total resistance of resistors connected in series and parallel combinations.

It also calculates the electric current for both combinations using Ohm's Law.

## Features
- Calculates total resistance in series.
- Calculates total resistance in parallel.
- Calculates current using Ohm's Law.
- Accepts multiple resistor values.
- Checks for invalid user inputs.
- Allows users to perform another calculation by restarting the programme.

## How to Run
1. Install Python on your device.
2. Download the `resistor_calculator.py` file.
3. Open the file using a Python environment.
4. Run the programme.
5. Enter the number of resistors.
6. Enter the resistance values in ohms.
7. Enter the supply voltage.
8. View the calculated results.

## Sample Calculation

### Input
- Number of resistors: 3
- Resistor 1: 10 Ω
- Resistor 2: 20 Ω
- Resistor 3: 30 Ω
- Supply voltage: 12 V

### Output
- Series resistance: 60 Ω
- Parallel resistance: 5.45 Ω
- Series current: 0.20 A
- Parallel current: 2.20 A
